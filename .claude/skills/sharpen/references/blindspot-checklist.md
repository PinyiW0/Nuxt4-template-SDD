# 盲點診斷清單

> 通用化規則：源自私人 prompt 語料分析的抽象化結果，原始語料不入 repo；本檔引號內的短句與案例皆為自造示意。
> 供 Phase 1 Step 2 逐項掃描；每條給偵測特徵、強／弱命中判準與可直接取用的反問句式。

## 使用原則

- **強命中＝必問**；**弱命中＝不問**，記入理解摘要的「殘餘假設」。
- 反問句式是素材，實際提問依「合併規則」歸併；一輪題數、選項數、追問輪數的上限以 SKILL.md 鐵則為準。
- **快速通道**：輸入已同時含**目標、驗收條件、授權邊界**三者 → 視為高品質交接 prompt，跳過全部掃描，直達摘要確認（摘要一行帶過）。此三項是「釐清充分性」判準，與 prompt-template 的「交辦三要素」（必填段）不同軸；快速通道輸入未給回報格式時，Phase 2 以（假設）補預設。

## 八大盲點

### B1 驗收條件缺席

- 偵測特徵：要求「做好／改好／弄成某個樣子」但全文無完成判準（無「驗收／通過／以某為準／像某參考」）；視覺、設計、文案、品質類任務最常見
- 強命中：視覺／設計／品質類任務，且無任何判準或參考錨點（參考圖、色票、數值、範例檔）
- 弱命中：技術任務且驗收可由慣例推得（如「修 lint」＝lint 全綠）
- 反問句式：「怎樣算完成？有參考圖／範例／數值標準嗎？」「哪些部分已經確認過、這次不能動？」

### B2 多目標混寫

- 偵測特徵：「然後／另外／順便／還有／再幫我／一併」出現 ≥2 次，或含 ≥3 個彼此無依賴的動詞短語
- 強命中：目標分屬不同檔案區域或不同性質（修 bug＋新功能＋流程操作混在一句）
- 弱命中：多個目標同屬一個小改動的自然步驟
- 反問句式：「這幾件事要一起做還是拆開？哪件優先？」「做完哪一件就可以先交付？」

### B3 授權邊界缺席

- 偵測特徵：任務會產生副作用（改檔、commit、push、開 issue／PR、裝依賴、刪東西、部署）但沒說可不可以
- 強命中：涉及不可逆或對外可見動作（push、merge、開 issue、部署、刪除）且未授權
- 弱命中：只在工作區改檔、隨時可還原
- 反問句式：「可以動哪些檔／目錄？」「要不要 commit／push？可以自己開 issue 嗎？」「可以裝新依賴嗎？」

### B4 指代與定位不明

- 偵測特徵：輸入 <20 字，或以「那／這／他／剛剛／上次」等指代詞開頭，且對話中沒有明確先行詞
- 強命中：無法從上下文確定指的是哪個 repo／檔案／分支／物件
- 弱命中：本 session 上文已明確出現先行詞
- 反問句式：「指的是哪個專案／檔案／分支？」「「那個」是指剛剛的哪一項？」

### B5 模糊價值詞無判準

- 偵測特徵：「怪／醜／亂／髒／慢／卡／比較好／優化／調整一下」等主觀詞，且無量化基準或參考對象
- 強命中：模糊詞是任務的核心要求（「把它弄好看」）
- 弱命中：模糊詞只是附帶感想，任務本體另有明確要求
- 反問句式：「「怪」具體是指哪裡？有想要的樣子（參考連結／截圖）嗎？」「「慢」是哪一段？可接受的秒數？」

### B6 素材無動詞

- 偵測特徵：輸入只有 URL／圖片／檔案路徑，沒有要對它做什麼的動作要求
- 強命中：素材單獨出現、零說明
- 弱命中：素材附一句模糊說明（「後端更新了」）——同時檢查 B1
- 反問句式：「要我拿這份素材做什麼？（比對／實作／開 issue／只是參考）」

### B7 跨專案與階段不明

- 偵測特徵：涉及多 repo 工作流（「同步／回灌／複製過去／跟某某一樣」）但未標明來源與目標 repo、分支或階段
- 強命中：改動會落地到哪個 repo 無法確定
- 弱命中：當前工作目錄即唯一合理目標
- 反問句式：「改動要落在哪個 repo／分支？其他 repo 要跟著同步嗎？」

### B8 外部協作無紅線

- 偵測特徵：任務是回覆他人／對齊外部規格／協商往返，但沒給立場：哪些可讓步、哪些是紅線
- 強命中：要代擬對外回覆或做取捨，且立場未知
- 弱命中：純內部整理，不對外
- 反問句式：「這次對齊的底線是什麼？哪些可以讓、哪些絕對不改？」

## 合併規則

1. 同類歸併：B4＋B7 併為一題「定位」；B1＋B5 併為一題「驗收判準」。
2. 提問優先序：**定位（B4/B7）→ 拆分（B2）→ 驗收（B1/B5）→ 邊界（B3）→ 紅線（B8）**；B6 命中時「要做什麼」永遠是第一題。
3. 超出一輪題數上限（見 SKILL.md 鐵則）的低優先項降級為假設。
4. 第 1 輪答案暴露新的強命中才允許追問；達鐵則輪數上限後一律記假設、不再問。

## 授權邊界預設欄位

B3 提問或組裝 prompt 時，逐項確認（未確認者採保守預設）：

| 欄位 | 保守預設 |
|------|----------|
| 可動檔案／目錄 | 僅任務直接相關檔；其餘唯讀 |
| commit／push | 不做，留給使用者 |
| 開 issue／PR | 不開，先列草案 |
| 裝新依賴 | 不裝，先提出 |
| 刪除／覆蓋既有檔 | 不做，先確認 |
