# 精準 prompt 範本

六段結構。必填三段（目標與動機／驗收條件／回報格式）即「交辦三要素」——與 `.claude/ops/model-dispatch.md` §2 同源；該檔不存在時本範本自足。

## 範本

```markdown
## 目標與動機（必填）
{做什麼＋為什麼要做——動機讓執行者在邊界情況能自行取捨}

## 範圍與現況
{在哪個 repo／分支／檔案；相關現況（已存在什麼、依賴什麼）；明確列出範圍外（Out of Scope）}

## 授權邊界
{可動哪些檔／目錄；可否 commit、push、開 issue／PR、裝依賴、刪檔；未列出者一律不得動}

## 驗收條件（必填）
{條列；每條可獨立判 Pass/Fail；寫結果不寫實作（What not How）；可測量}

## 回報格式（必填）
{只回結論＋證據（檔案:行號）；產物超過 30 行寫到檔案、回報路徑＋5 行內摘要；查不到明說、禁止編造}

## 參考與遵循（選填）
{動工前要先讀的規範／skill／文件路徑；要遵循的專案慣例}
```

## 填寫要點

- 驗收條件 **3–7 條**為宜；塞不下代表範圍太大，回頭拆任務（呼應 B2）。
- Phase 1 未釐清的低衝擊資訊，以「（假設）……」寫入對應段落——讓執行者知道哪裡可推翻、推翻時要回報。
- 視覺／設計類任務的驗收條件必含**參考錨點**（圖／色票／數值）與**不可變清單**（已確認不准動的部分）（呼應 B1）。
- 產出語言跟隨使用者輸入語言。
